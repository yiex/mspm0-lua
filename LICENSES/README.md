# Licenses

本目录保存仓库中第三方组件的完整许可证文本：

- `MPL-2.0.txt` — Mozilla Public License 2.0，适用于 IDE 中链接的
  `serialport`、`dwrote`、`option-ext`（运行时）与 `cbindgen`（构建期）等
  crate。MPL-2.0 是文件级弱 copyleft：这些组件的源代码可从
  [crates.io](https://crates.io) 获取，本仓库其余代码仍以 MIT 发布。

其余组件的许可证文本随源码保留（如 `mspm0_lua/third_party/lua/LICENSE`、
`mspm0_lua/third_party/littlefs/LICENSE`、`mspm0_lua/third_party/mspm0/LICENSE`、
`gpui_ide/vendor/gpui/LICENSE-APACHE`、`gpui_ide/font/Tuffy-LICENSE.txt`）。
