# OLED fonts

Place licensed `.ttf` or `.otf` files in this directory. `config.json` stores
the selected Chinese and Latin font file names. The bundled `Tuffy.ttf` is a
public-domain Latin font; its original declaration is in `Tuffy-LICENSE.txt`.
No Chinese font is redistributed without permission. If the selected local
Chinese font is absent, the rasterizer falls back to an installed black font.
